# Security Policy

## Supported Versions

Until tagged releases are published, security fixes target the current default
branch. Older source snapshots are not maintained as separate release lines.

## Reporting a Vulnerability

Use **Report a vulnerability** in this repository's Security tab. Do not include
vulnerability details in a public issue.

Include the affected commit, macOS version and model, impact, reproduction steps,
and any suggested mitigation. Remove credentials and unrelated private data.
